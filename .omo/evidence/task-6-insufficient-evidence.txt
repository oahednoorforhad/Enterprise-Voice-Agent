Task 6 — Reasoning Pipeline: Insufficient evidence deterministic fallback
=========================================================================

Date: 2026-06-10
Related: Sprint 3, FR-07 (Evidence-Based Reasoning), hallucination prevention (PRD §489-507)

Input
-----
- EvidencePackage with 0 items, 0 failed_tools
- Intent: "billing_inquiry" (non-greeting)
- No customer context

Pipeline execution
------------------
- Path: Insufficient evidence (deterministic, NO LLM call)
- LLMClient.generate_structured is NEVER called
- Hard-coded fallback response

Output
------
- conclusion: "I do not have enough information to answer your question. Please provide more details or contact support for assistance."
- evidence_cited: []
- reasoning_type: "insufficient_evidence"
- confidence: 0.0
- warnings: ["No evidence was retrieved to support this turn"]

Greeting variant
----------------
When intent IS "greeting" or "other" with empty evidence:
- conclusion: "Hello {name}! How can I help you today? ..." (personalised when name in customer_context)
- reasoning_type: "greeting"
- confidence: 1.0
- warnings: []
- Also deterministic — no LLM call

Design rationale
----------------
- Hallucination prevention: The LLM is never invoked without evidence
- The system prompt explicitly forbids using external knowledge
- PRD mandates "I do not have enough information to determine that" for insufficient evidence
